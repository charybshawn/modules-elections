# Elections tag vocabulary

The shared list of subject tags. Every research skill picks tags from here: 1 to 3 per item, the most specific that fit. A new tag needs a `<vocabulary>` entry in the same import file, and the hand-off has to flag it. Each tag files under one heading (`Entry::TOPICS`). Planks, statements, articles, Community Pulse issues and scorecard statements can be tagged; background facts aren't, and a plank's statements show the plank's tags.
